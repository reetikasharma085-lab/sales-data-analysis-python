# Sales Data Analysis using Python

Analyzed 500+ sales orders using Python, Pandas & Matplotlib.

## Key Insights
- Laptop contributes 44% of total sales
- April is the peak sales month, November is lowest
- Delhi is the largest market

## Tools Used
Python, Pandas, Matplotlib, Google Colab

## Files
- sales.csv - Raw sales data
- analysis.py - Data cleaning & analysis code
